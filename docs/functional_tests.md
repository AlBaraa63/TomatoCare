## Edge cases to spot-check

- Rotate device mid-inference → no crash, result shows on the resumed orientation
- Background the app during inference → returns to result on resume
- Pick the same gallery image twice in a row → both scans land in history
- Import a malformed JSON file → Snackbar "Invalid file format", existing history unchanged
- Switch language while on Result screen → re-renders in new language; selected growing method preserved
