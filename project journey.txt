TomatoCareNet
 model uses a custom architecture designed to be efficient (mobile-friendly) while maintaining high accuracy. Here are the layers broken down simply:

1. Convolutional Blocks (The "Eye")
These layers scan the image to extract features like edges, textures, and shapes. The model has 4 main blocks, each increasing in complexity:

ConvBlock 1: Takes the raw image and finds simple features (3 $\to$ 32 channels).
ConvBlock 2: Finds patterns (32 $\to$ 64 channels).
ConvBlock 3: Finds complex parts of the leaf (64 $\to$ 128 channels).
ConvBlock 4: Recognizes high-level disease structures (128 $\to$ 256 channels).
Each block contains Convolutional layers, Batch Normalization (stabilizes learning), ReLU (activation), Max Pooling (reduces size), and Dropout (prevents overfitting).

2. Attention Mechanism (The "Focus")
Squeeze-and-Excitation (SE) Block: This special layer helps the model "pay attention" to the most important channels (disease spots) and ignore background noise. It's like squinting to see the details better.

3. Global Pooling (The "Compressor")
Global Average Pooling: Instead of keeping a large grid of numbers, this squashes the feature maps into a single vector (1x1x256). This drastically reduces the number of parameters, making the model very small and fast for mobile devices.

4. Classifier (The "Decision Maker")
This final section takes the compressed features and decides which disease matches best.

Linear Layer: Expands to 512 neurons to analyze features.
Linear Layer: Compresses to 256 neurons to refine the decision.
Output Layer: Outputs the probability for each of the 10 classes (diseases).
